Homeostat unit, redrawn

A modern redraw of Ashby's notebook sketch, plus the wiring for four units. It uses the notebook page, checked against Figure 8/2/3 of Design for a Brain. Anything still inferred is marked.

The output is a current loop

Anode, relay, OUT.b, whatever you connect, OUT.a, self-coil network, +100 V. The relay and self coil sit in series with the load.

An unconnected unit is dead

With OUT open, no current flows, so L4 gets no feedback and the relay can never trip. The units need each other to run.

Wire the inputs in series

Each output goes through one input on each of the other three units. That makes four closed loops and sixteen jumpers.

Fig. 1: Schematic of one unit

The magnet position sets the grid voltage through the trough, the valve turns that into anode voltage, and the difference from +100 V drives current round the output loop. Three inputs and the self coil push the magnet.

Fig. 3: Four units connected

Each unit has three external inputs and one output, so four units make a fully connected network: every unit drives the other three. L4 supplies the fourth coil, the diagonal of the matrix, and needs no external wiring.

Read the figure as a matrix. Each row is one closed output loop, and each column is the set of coils on one magnet.

All four units share 0 V, +150, +100, +2 and −15 V. Give each uniselector drive its own feed so a stepping pulse does not disturb the rails.

Why series, not parallel

  • The pots are built for it. Each is a shunt on a current line. Turned to zero, it short-circuits its own input. In series that simply gives zero weight. In parallel it would short the whole output and starve the other two units.
  • Ashby already does it once. The self network and relay are both in series in the output. Series inputs extend the same pattern.
  • The weights stay independent. The same current passes through all four networks, so setting one pot, or one uniselector step, barely changes what another unit receives.
  • The relay stays calibrated. It reads the same current that L4 and the other units receive, whatever the input settings are.

To take an input out of action, turn its pot to zero and leave the wiring alone. That keeps the loop closed. If the third way of switch A turns out to be a plain open, don't use it, because it would break the whole loop.

The book's output terminals show the same series chain

Fig. 8/2/3 has six output ends, and they look like a fork. Enlarged, the two main wires reach only the outermost ends. The two inner chevrons do not touch them. Each chevron links the return of one output pair to the start of the next, which is a series chain built into the sending unit.

This uses three two-wire cables per unit, 24 wires in all. The ring in Fig. 3 uses 16. The two are the same circuit, and they only differ in where the links sit.

The rotating scheme

The alternative rule is 1.OUT.a → 2.IN1 → 3.IN2 → 4.IN3 → 1.OUT.b, stepped round for each unit. Tracing the coloured diagram gives exactly this rule. It has the same four loops as Fig. 3, in the same order. Only the input numbers change:

The three input channels are electrically identical, so this swap changes nothing. Its real benefit is that every unit's harness is the same, because INk always comes from the unit k steps back. It is not the only way that balances. Balance is set in each unit by E (RV5), which puts the anode at the fixed voltage. Any arrangement that gives each unit one input from each of the others works, which is 1,296 slot assignments.

Safety

Every coil, pot and input terminal sits near +100 V above chassis, including when the unit is idle. Treat the switches and all jumpers as live.
