Homeostat 4-D Path

PT's minimal Homeostat model: four units of magnet and trough, coupled all-to-all, with 25-position uniselectors and a shared timer. The four deflections (TL, TR, BR, BL) form one point in 4-D, drawn inside the ±45° tesseract.

Drag to turn in 3-D. Colour = the unit(s) whose uniselector stepped last.

Run

Restart applies the preset, seed and polarity setting. Model time per frame is fixed (3 RK4 steps of 10 ms), so a given seed always traces the same path at any speed.

Exports use the view as it is now; untick 4-D spin first to hold an angle. The SVG is the 2-D projection on screen, one polyline per colour (one pen each). The 3-D path is the 4-D perspective step only, before the 3-D turn: x, y, z in mm, ready to sweep a tube along. Send to the arm passes that same path to the layout editor on armster, where it is placed, planned and run. Both skip samples that moved under 0.25°, so the settled tail doesn't pile up; the 4-D data keeps every sample.
